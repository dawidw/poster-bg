The Mac app

The Study of Space Mac app does not collect, store or share any personal data. It has no accounts, no analytics and no advertising. It does not send anything over the network: the pictures are drawn on your Mac by the same generator that runs on this website, and they are saved only where you choose.

  • Wallpapers you set are written to the app's own folder on your Mac so macOS can show them. You can delete them at any time.
  • Files you save as PNG go to the place you pick in the save dialog.

The website

This website uses GoatCounter, a privacy-friendly counter. It sets no cookies, does not track you across sites and does not store personal data. It records only anonymous page views, the page you came from and your broad browser and screen size. The generator keeps its state in the address of the page, so a link you copy contains the picture you made and nothing else.

The site is hosted on GitHub Pages, which keeps its own server logs as described in GitHub's privacy statement.
